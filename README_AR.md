# منصة حجز المواعيد — تغطية الحملة الانتخابية

واجهة عربية RTL متجاوبة مع الهاتف والحاسوب. تتضمن:
- طلب حجز نشاط/تغطية انتخابية.
- اختيار التاريخ والوقت.
- لوحة إدارة عبر تسجيل الدخول.
- مراجعة الطلبات وتغيير حالتها.
- عرض حالة الطلب باستخدام رقم الهاتف (ميزة أولية؛ انظر ملاحظة الخصوصية).
- قاعدة بيانات Supabase وسياسات وصول (RLS).

## مهم قبل النشر
الملفات وحدها لا تنشئ قاعدة البيانات أو حساب الإدارة ولا ترسل رسائل بريد تلقائيًا. يجب إكمال الخطوات التالية. الواجهة لا تحفظ الحجوزات في وضع المعاينة إذا لم تضف إعداد Supabase.

## 1) إنشاء قاعدة البيانات
1. افتح https://supabase.com وسجّل الدخول وأنشئ مشروعًا جديدًا.
2. من لوحة المشروع افتح **SQL Editor** ثم **New query**.
3. انسخ محتوى `schema.sql` كاملًا وشغّله بزر **Run**.
4. من **Project Settings > API** (أو Connect بحسب الواجهة) انسخ **Project URL** و**anon/public key** فقط.

## 2) إعداد الاتصال
1. انسخ `config.example.js` وسمِّ النسخة `config.js`.
2. استبدل `YOUR-PROJECT` و`YOUR_SUPABASE_ANON_PUBLIC_KEY` بالقيم التي نسختها.
3. في `index.html` أضف السطر التالي قبل `app.js` (موجود أصلًا قرب نهاية الصفحة) كي يحمل إعداد الاتصال:
   `<script src="config.js"></script>`
   يجب أن يصبح ترتيب السكربتات في آخر الصفحة:
   `config.js` ثم `app.js`.
4. احفظ الملفين. **لا تضع service_role key في الموقع مطلقًا.**

## 3) إنشاء حساب الإدارة
1. في Supabase افتح **Authentication > Users > Add user** وأنشئ حساب بريد وكلمة مرور خاصًا بالإدارة.
2. انسخ UUID الخاص بالمستخدم من جدول Users.
3. افتح SQL Editor وشغّل الأمر التالي بعد استبدال UUID:
   `insert into public.admin_users (user_id) values ('UUID-هنا');`
4. اختبر تسجيل الدخول من زر **دخول الإدارة**. لا تنشئ حسابات إدارة عامة أو تشارك كلمة المرور.

## 4) النشر على Netlify
### الطريقة الأسهل من الحاسوب
1. سجّل الدخول إلى https://app.netlify.com
2. اختر **Add new site > Deploy manually** (قد تختلف التسمية قليلًا).
3. فك ضغط ملف ZIP واسحب مجلد الموقع الذي يحتوي `index.html`, `style.css`, `app.js`, `config.js` إلى منطقة النشر.
4. افتح رابط الموقع واختبر إرسال طلب وتسجيل الدخول وتحديث الحالة.

### من الهاتف
يمكن فك ضغط الملف بتطبيق ملفات يدعم ZIP، ثم فتح Netlify من المتصفح بوضع سطح المكتب واتباع خطوات النشر اليدوي. إن لم يسمح المتصفح برفع المجلد، استخدم حاسوبًا أو ارفع الملفات إلى GitHub ثم اربط المستودع بـ Netlify.

## 5) الإشعارات
النسخة الحالية تُظهر حالة الطلب داخل الموقع، لكنها **لا ترسل بريدًا أو SMS تلقائيًا**. لإرسال إشعارات مؤكدة، اربط Supabase Edge Function مع مزوّد بريد (مثل Resend) أو خدمة SMS، واجعل المفتاح السري داخل إعدادات الخادم فقط. لا تضع مفاتيح الإرسال في `app.js` أو `config.js`. بعد تحديث الحالة، يمكن تشغيل الوظيفة لإرسال رسالة لصاحب الطلب أو لمسؤول التنسيق.

## ملاحظات أمنية وتشغيلية
- سياسة RLS تقصر قراءة الطلبات وتعديلها على حسابات أُضيفت إلى `admin_users`.
- كل زائر يستطيع إرسال طلب، لكن لا يستطيع قراءة جدول الطلبات مباشرة.
- متابعة الطلب بالهاتف فقط ليست تحققًا قويًا؛ يمكن لمن يعرف رقم هاتف شخص أن يستعلم عن الحالة. للإطلاق الفعلي يُفضّل استخدام رمز تتبع عشوائي أو رابط تحقق يُرسل إلى البريد/الهاتف.
- الفهرس الحالي يمنع أكثر من طلب نشط في الوقت نفسه والتاريخ نفسيهما. إذا كان بالإمكان تغطية أنشطة متعددة بالتوازي، عدّل قاعدة الحجز قبل التشغيل.
- لا تضف معلومات حساسة لا تحتاجها عملية التنسيق.
- اختبر السياسات بحساب زائر وحساب إدارة قبل مشاركة الرابط علنًا.

## الملفات
- `index.html`: واجهة الحجز ولوحة الإدارة.
- `style.css`: التنسيق المتجاوب.
- `app.js`: منطق النموذج والدخول والإدارة.
- `config.example.js`: مثال إعداد الاتصال.
- `schema.sql`: الجداول وسياسات الوصول.


## تثبيت تطبيق «المرصد الانتخابي» على الهاتف (PWA)
بعد نشر هذه الملفات على Netlify باستخدام HTTPS، افتح رابط الموقع في Chrome على Android ثم قائمة ⋮ واختر «تثبيت التطبيق» أو «إضافة إلى الشاشة الرئيسية». على iPhone افتح الرابط في Safari ثم مشاركة > إضافة إلى الشاشة الرئيسية. هذه نسخة ويب قابلة للتثبيت وليست حزمة متجر Google Play/App Store. يجب الاتصال بالإنترنت لاستخدام الحجوزات وقاعدة Supabase؛ التخزين المؤقت يساعد على فتح الواجهة فقط ولا يتيح إرسال الحجوزات دون اتصال.
